# 🐍 Змей-Хапуга 3D

Сатирическая воксельная 3D-аркада в духе классической Snake 3: жадный змей с человеческим лицом гоняется за горожанами, каждый пойманный встаёт в хвост-очередь — чем длиннее очередь, тем сложнее не врезаться в самого себя.

**Играть:** открой `index.html` в браузере — игра целиком в одном файле, без зависимостей, работает офлайн.

## Управление
- ←/→ (или A/D) — повороты
- ↑/W — ускориться, ↓/S — притормозить
- P — пауза

## Что внутри
- Камера от третьего лица, погоня за змеем
- Уровни с целью по пойманным и сохранением прогресса; первый уровень — инструктаж от говорящего змея
- Уникальные карты: город / склад / парк / лабиринт / площадь, растущий размер, сезоны (лето, осень, зима, сумерки)
- Убегающие горожане, депутат-ловушка, поедающий деньги, супергерой со щитом-куполом
- Дроны-бомбардировщики, бомбы, взрывы с оглушением, ускорители, кроссовки и кофе для NPC
- Мини-карта, озвучка реплик, воксельная графика на Three.js в одном HTML-файле
